# Changelog

All notable changes to Revenge are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Independent reconstruction of the application and its supporting modules.
- CodeQL and Semgrep workflows that run only when code files change.
- Issue templates for error reports, feature requests, appreciation, and blank
  issues.
- Project documentation and a release-aware download page.

### Security

- Semgrep rules for hardcoded credentials, cleartext endpoints, WebView
  JavaScript, and disabled hostname verification.
