# Code of conduct

## Our standard

Be direct about code and kind to people. Disagree with an idea, not its author.
Assume a report of harm is made in good faith. Give newcomers the same patience
you wanted when you started.

Unacceptable: harassment, personal attacks, discriminatory language, publishing
someone's private information, and sustained disruption of discussions.

## Scope

This applies in the repository, issue tracker, review threads, and any space
where you represent the project.

## Enforcement

Report incidents to the maintainer through a private GitHub message or a
security advisory if confidentiality matters. Reports are read by the maintainer
only. Responses scale with severity: a private clarification, a public
correction, a temporary ban, or a permanent ban. Retaliation against a reporter
is itself a violation.

## Attribution

This policy is intentionally short. It is not derived from a template; it states
the behaviour this project expects and how reports are handled.
